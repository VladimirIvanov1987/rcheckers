# 🏁 Russian Checkers Rules

Russian Checkers is a classic strategy board game.

### ♟ Regular Pieces (Men)
*   **Move:** Diagonally **forward** only, one square at a time.
*   **Capturing:** Capturing is **mandatory**.
*   **Backward Capture:** Regular pieces **CAN capture backwards**.

### 👑 Kings (Dames)
*   Reaching the opposite end creates a **King**.
*   **Flying Kings:** Kings can move diagonally any distance across free squares.
*   Kings can capture from a distance and land on any empty square behind the target.

### ⚔️ Key Mechanics
1.  **Forced Capture:** If a capture is available, you must take it.
2.  **Chain Jumping:** Multiple jumps in one turn are mandatory if available.

---

### 🤝 Draws
The game automatically detects a draw in these situations:

1.  **Agreement:** Players agree via the "Offer Draw" button.
2.  **Threefold Repetition:** The exact same position occurs **3 times**.
3.  **Move Limits (No captures):**
    *   **15 Moves Rule:** If you have 3 Kings (or more) vs 1 enemy King, you have 15 moves to force a win.
    *   **5 Moves Rule:** If players have 1 King each (or 2 vs 1), the game ends quickly if no progress is made.
    *   **30 & 60 Moves Rule** If 30 (in King endings) or 60 moves pass without any piece being captured or any regular pawn moving, the game ends in a draw.
